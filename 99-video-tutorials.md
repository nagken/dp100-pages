## How to use these videos

1. **First pass - Microsoft Learn Live "Prepare for DP-100"** (one sitting). Walks every skill area in the official outline.
2. **Second pass - AI Show + Azure Friday** episodes for any topic where you didn't feel confident (MLflow, AutoML, endpoints, Responsible AI, MLOps).
3. **Third pass - SDK v2 / CLI v2 walkthroughs** so the exam syntax is muscle memory. Skip anything tagged SDK v1.
4. Then take the **Practice Assessment** (see the sidebar) before scheduling the real exam.

> Tip: DP-100 mixes *conceptual* questions ("which compute target should you use?") with *syntax* questions on SDK v2 / CLI v2 / MLflow. Watch at least one full SDK v2 walkthrough - the YAML and Python shape recurs across many exam scenarios.
